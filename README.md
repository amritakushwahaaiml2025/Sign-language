## About the Project

SignSpeak AI is a real-time computer-vision-based sign language recognition and speech system.

The system uses webcam input, hand landmark detection, a trained machine-learning model, and text-to-speech technology to recognize supported sign-language words and provide spoken output.

## Core Technologies

- Python
- TensorFlow
- OpenCV
- MediaPipe
- NumPy
- Pandas
- pyttsx3
- Computer Vision
- Machine Learning
- Text-to-Speech

## Supported Sign Vocabulary

The current system recognizes the supported trained word classes included in the project model.
